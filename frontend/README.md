# Innerarc frontend

Expo (React Native, TypeScript) app shell for Module 1. Screens are placeholders for Flow A (onboarding) landing: Splash → Auth → Home.

## Run

```bash
npm install
npx expo start
```

Theme tokens in `src/theme.ts` follow the UI/UX brief: off-white / soft grey base, a single muted teal accent, heavier numerals. Logging actions on Home are disabled until later modules.
